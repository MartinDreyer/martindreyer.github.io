# martindreyer.github.io

Personlig hjemmeside og CV for Martin Dreyer, udvikler og journalist.

Live: [martindreyer.dk](https://martindreyer.dk)

## Struktur

- `index.md` – sidens indhold (profil, teknologier, arbejde, uddannelse)
- `assets/` – billeder og ikoner
- `CNAME` – custom domain til GitHub Pages
- `favicon.ico`

## Udgivelse

Siden hostes på GitHub Pages og bygges automatisk fra `main`. Push en ændring til `main`, så er den live efter kort tid.
